# refs

Lưu tài liệu tham khảo được phép sử dụng, đường dẫn nguồn gốc thư viện,
mô tả giấy phép mã nguồn mở và ngày truy cập. Không sao chép nguyên các
bài báo, bài giảng hoặc repository của người khác nếu không có quyền.

Các nguồn tài liệu chính thức có thể tham khảo:
- Python Socket: https://docs.python.org/3/library/socket.html
- Python socketserver: https://docs.python.org/3/library/socketserver.html
- Cryptography RSA: https://cryptography.io/en/latest/hazmat/primitives/asymmetric/rsa/
- Cryptography AES-GCM: https://cryptography.io/en/latest/hazmat/primitives/aead/
- Cryptography HKDF: https://cryptography.io/en/latest/hazmat/primitives/key-derivation-functions/
- GitHub pull requests: https://docs.github.com/en/pull-requests
